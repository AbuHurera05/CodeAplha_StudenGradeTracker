# 📚 Student Grade Tracker

A comprehensive Java application for managing and tracking student grades with advanced features.

## 🎯 Features

- ✅ Add single/multiple students
- ✅ View all students with grades
- ✅ Statistics (Average, Highest, Lowest)
- ✅ Grade distribution analysis
- ✅ Search students by name
- ✅ Remove students
- ✅ Save/Load data to/from CSV files
- ✅ Generate detailed reports
- ✅ Grade letter conversion (A, B, C, D, F)
- ✅ Top performers identification

## 🛠️ Technologies

- Java 8+
- OOP Concepts
- Collections Framework
- File I/O
- Streams API
